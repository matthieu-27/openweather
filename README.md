# Exercice 2

Créer un compte sur https://openweathermap.org/api et y créer une clé d’API.
Utiliser https://openweathermap.org/forecast5 > https://openweathermap.org/forecast5#name5
pour obtenir des données de prévisions météorologiques à 5 jours. Utiliser ces données pour afficher
dans un programme Python la température minimale et la température maximale pour les 5 jours à
venir à Mérignac, Saint-Geours-de-Maremne et Toulouse.

## Installation

Clone this repository

```sh
uv sync
uv run openweather
```
